## Research & Projects

### Structured Extrema Errors in Classical Surrogates for Viscous Burgers

**Research paper** on understanding and correcting structured errors made by ML surrogates for nonlinear PDE dynamics.

- Compared **Kernel Ridge, Ridge, ExtraTrees, and Random Forests** and analyzed residuals using held-out tests, geometric diagnostics, negative controls, and spectral analysis.
- Developed a learned correction and evaluated it on one-step prediction and recursive rollout.

**Status:** Accepted at **ML4PS 2026**.

**ML skills:** kernel methods · ensemble methods · regression · residual analysis · model evaluation

### Differentiable Ocean Sensing — Sensor Placement & Data Assimilation

- Extended **Chapron, Fablet & Stéphan's differentiable Gumbel-Softmax sensor-placement framework**, combining **Optimal Interpolation (OI)** with learned **anisotropic and non-stationary covariance kernels** for sparse Sea Surface Height (SSH) reconstruction.
- On **25 NATL60 ocean states**, achieved **38% lower RMSE** than the isotropic baseline. Evaluated robustness under **six forecast-error types and three severity levels**, maintaining an average **33% RMSE improvement** over the isotropic baseline.

**Research areas:** data assimilation · differentiable optimization · optimal sensor placement · non-stationary covariance learning · robustness analysis

[View Repository](https://github.com/Youssef-obr/differentiable-ocean-sensing)

### Classical ML Surrogates for the 1D Burgers Equation

Built and compared classical ML models for learning the time evolution of the viscous Burgers equation directly from spatial data.

- Tested **linear/polynomial regression, RBF Kernel Ridge, gradient-boosting residual correction**, model selection, ablations, and recursive rollout.
- Evaluated generalization, error accumulation, and inference speed against a numerical PDE solver.

**ML skills:** supervised learning · regression · regularization · kernels · gradient boosting · validation
